# Nordveil — Shield Pro storefront

Static, Shopify-style product page for a 3-layer windshield / side-window / mirror cover.

- `index.html` — the whole store (inline CSS/JS, no build step). Open it in a browser.
- `assets/` — optimised product photos, incl. the regraded before/after comparison.

Variants: Hatchback €49 · Sedan €79 · SUV €119 (edit the `V` array in `index.html`).
